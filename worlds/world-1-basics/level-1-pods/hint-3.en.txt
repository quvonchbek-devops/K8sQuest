The error is explicit: `executable file not found` — there is no command
called `nginxzz`. The nginx image runs fine with no custom command, so the

IMPORTANT: a pod's `command` field cannot be changed (it is immutable — only
`image` can be swapped). So the pod is recreated:

    kubectl delete pod nginx-broken -n k8squest
    kubectl run nginx-broken --image=nginx -n k8squest

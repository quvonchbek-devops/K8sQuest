🧭 Yo'naltiruvchi maslahat:

Ingress NOTO'G'RI PATH bilan sozlangan.

Hozirgi holat:
```yaml
spec:
  rules:
  - host: myapp.local
    http:
      paths:
      - path: /api        # ❌ NOTO'G'RI!
        pathType: Prefix
```

So'rov: http://myapp.local/ → Path: "/"
Ingress qoidasi: path: "/api"
"/" "/api" bilan boshlanadimi? YO'Q! → 404 Not Found

Tuzatish: path ni "/api" dan "/" ga o'zgartiring.

Path turlari:
- **Prefix**: /path va /path/boshqa-narsa ga mos
- **Exact**: Faqat aniq path ga mos

Qoidani O'Z KO'ZINGIZ bilan ko'ring — path va backend bir buyruqda:

    kubectl get ingress web-ingress -n k8squest -o jsonpath='{.spec.rules[0].http.paths[0]}'
    kubectl describe ingress web-ingress -n k8squest

Backend to'g'ri (`web-service:80`), muammo esa `path` da: `/api` faqat
`/api...` bilan boshlanadigan so'rovga mos keladi, ildizga (`/`) kelgan
so'rov hech qanday qoidaga tushmaydi va Ingress 404 qaytaradi.

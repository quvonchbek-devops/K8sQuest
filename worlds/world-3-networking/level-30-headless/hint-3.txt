✅ Yechim maslahat:

Service da clusterIP ni None ga o'zgartiring:

```bash
kubectl delete service web-cluster -n k8squest
kubectl apply -f solution.yaml
```

Asosiy o'zgarish — FAQAT BITTA QATOR:
```yaml
spec:
  clusterIP: None  # ✅ IP manzildan None ga o'zgardi
```

Tekshirish — service headless ekanini tasdiqlang (CLUSTER-IP: None):

    kubectl get service web-cluster -n k8squest

Per-pod DNS ni sinash. Terminal bir martalik va TTY yo'q, ya'ni `-it ... -- sh`
bilan pod ichiga KIRIB bo'lmaydi — buyruqni pod ga BERIB yuborasiz va natijani
log dan o'qiysiz:

    kubectl run dns-test --image=busybox:1.28 --restart=Never -n k8squest --command -- nslookup web-0.web-cluster.k8squest.svc.cluster.local
    kubectl logs dns-test -n k8squest
    kubectl delete pod dns-test -n k8squest

Log da web-0 ning ANIQ IP manzili ko'rinishi kerak (headless service har pod
uchun alohida A yozuv beradi). Xuddi shu buyruqni `web-1` uchun ham
takrorlang — IP boshqacha bo'ladi.

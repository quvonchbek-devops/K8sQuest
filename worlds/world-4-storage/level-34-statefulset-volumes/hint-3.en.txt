✅ Hint 3: Full solution

The StatefulSet uses ONE shared PVC for all pods. For each pod to get its own
disk it needs `volumeClaimTemplates` — a field that cannot be changed on an
existing StatefulSet (immutable), so the resource is recreated.

1. Delete the StatefulSet (the pods go with it):

    kubectl delete statefulset postgres-cluster -n k8squest

2. Delete the shared PVC — it is no longer needed:

    kubectl delete pvc database-storage -n k8squest

3. Apply the variant with volumeClaimTemplates (after `Show solution` the file
   is in your session):

    kubectl apply -f solution.yaml -n k8squest

4. Look at the result — a SEPARATE PVC is created per pod:

    kubectl get pvc -n k8squest
    kubectl get pods -n k8squest -l app=postgres

The names look like `database-storage-postgres-cluster-0`, `-1`, `-2`: the
StatefulSet appends the pod name to the template name. The PVCs must be `Bound`
and the pods must come up in order (0 → 1 → 2).

Watch out: `volumeClaimTemplates[].metadata.name` and the container's
`volumeMounts[].name` MUST match — otherwise the pod cannot find the volume.
